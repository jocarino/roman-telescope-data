# Design & web curators / newsletters

**Status:** not started · **Effort:** medium (one evening to build the kit, ~2 hours to send the first wave) · **Payoff:** high — the highest-taste, lowest-cost audience we can reach, and placements cascade · **Hub:** [Marketing plan](./README.md)

## The bet

Design curators are the only free channel where a beautiful, weird, hand-built thing beats a well-funded thing. They need one link and one image per slot, every week, forever — we are supply, not a favour. The site is unusually well-suited: ~5,700 colour swatches is an *unusual dataset*, palette export as hex/CSS/.ase is *directly useful to the reader*, and "no framework, no build toolchain" is a craft story a front-end newsletter can print as-is. None of them care about exoplanets, so the exoplanet part is the hook, never the pitch.

## The angle per outlet

One line each. Never lead with astronomy.

- **Naive Weekly** — "A hand-built site, no framework, that computes the colour of 5,700 real planets and lets you take the palette home." Quiet-web pedigree is the whole pitch.
- **Web Curios** — Delight and absurdity of scale: *every known planet has a hex code now, and here is the one that is cobalt blue.* Write it in his register: funny, unpolished, human.
- **Hover States** — Purely visual: the oscilloscope/CRT interface, the phase-angle slider changing a planet's colour in real time, the host-star lamp duotone. Send the GIF.
- **Sidebar.io** — Framed as a designer's tool: palette export to hex/CSS variables/.ase from an unusual source. Sidebar rewards effort-heavy, non-listicle work.
- **Design Spells** — Submit *one* interaction: the phase slider, or the true-colour/Roman-view toggle re-keying every swatch on the page at once.
- **Bruce Lawson / Frontend Focus** — Craft: 5,700 pages, static, htmx + Alpine, no build step, no framework; the entire dataset ships as JSON. That's the headline for a front-end audience.
- **Waxy / Tiny Awards / kottke** — Small-web sincerity: one person, evenings, physics instead of a design tool, honest about what's modelled vs measured.
- **things magazine** — "Objects, collections and discoveries" — this is a colour catalogue of every known object of a class. That's their exact register.
- **It's Nice That / Creative Boom** — A visual system derived from data with no human colour choices: the palette was decided by physics, not taste.
- **Recomendo** — Six-line recommendation format: "Free palette generator sourced from real planetary spectra; export to CSS or Adobe .ase."
- **Colossal** — Data-as-art: the full 5,700-swatch grid as a single image.
- **Fonts In Use** — Only if we run a distinctive named face; the use is "scientific instrument UI revival".

## What has to exist first

Nothing goes out before the press kit exists at a stable URL. See [Press kit](./02-press-kit.md) — this channel's specific requirements:

- **Hero shot** — the gallery grid, wall-to-wall swatches, no browser chrome. 2400×1500 PNG (deliver a 1200×750 too). This is the image most editors will actually run.
- **Palette-export screenshot** — one planet's detail page showing the 5-stop ramp *plus* the export panel with hex / CSS variables / .ase visible. 1600×1200. This is the "useful to a designer" proof.
- **Phase-slider clip** — 8–12 s, 1200px wide, MP4 **and** GIF under 5 MB. Design Spells and Hover States effectively require motion.
- **True-colour vs Roman-view pair** — side-by-side, 1600×900, one label each. The signature feature; make it legible at 600px wide.
- **Full-grid poster** — the whole 5,700-swatch field as one flat image, 3000px square. For Colossal and for social.
- **OG card** — 1200×630 (already shipped per-planet; expose one canonical site card).
- **40-word description** — for a Sidebar-style one-liner slot.
- **150-word description** — for a newsletter blurb; must contain "modelled, not photographed".
- **Credit + licence line** — data source (NASA Exoplanet Archive), model provenance, and what an editor may reuse. See [Credit the scientists](./13-credit-the-scientists.md) and [Open data](./06-open-data.md).
- Every image needs alt text written already. Curators paste it.

## Figma Community & swatch packs

**Verdict: worth it, but only after the newsletter wave, and time-boxed to one evening each.** Both platforms have their own internal search with essentially zero astronomy content, so we'd own the term. Both are evergreen — they keep delivering after the newsletter spike decays. Neither will produce a big number.

- **Figma Community file — "Exoplanet Palettes"**: publish ~40 curated planets (the solar-system anchors, the extremes: darkest, bluest, most reflective, plus the Roman tech-demo targets) as named colour **variables/styles**, each with a description string carrying the planet name, host star, and the model assumptions. One cover frame (the 5,700 grid) and one "how these were computed" frame linking to <SITE_URL>. Cost: an evening. Tag it *color, palette, science, data, space*.
- **Procreate `.swatches` pack**: the same 40 planets as `.swatches` files, given away free on Gumroad (search demand for Procreate palettes is real and the field is crowded but purely aesthetic — "colours from real planets" is a genuine differentiator). Cost: an hour, since the generation is scriptable from `planets.json`.
- **Do not** build a Figma *plugin*. Review overhead and maintenance for one person, no.
- Both must carry the same honesty line and a link back with its own UTM.

## Sequencing

1. **Press kit first.** No pitch without images.
2. **Pitch the four core outlets before Hacker News**, not after: Naive Weekly, Web Curios, Hover States, Sidebar. Curated newsletters like discovering things; being #3 on HN first makes it stale. Small newsletters also have 1–2 week lead times, so early is free.
3. **Wave one: 4 emails, one evening.** Wave two (Bruce Lawson, Frontend Focus, Waxy/Tiny Awards, kottke, things magazine, Design Spells) a week later, once you can say "featured in X".
4. **Then** [Show HN](./09-show-hn.md), then let Hacker Newsletter/Muzli pick it up on their own.
5. **Never follow up.** These are one-person inboxes with hundreds of unread pitches. One email, no chaser, no "just bumping this". Re-pitching a *different, newer* feature in six months is fine; re-pitching the same link is not.
6. **Personalise the first line of every email** or don't send it. Reference a specific recent issue.
7. **What one placement unlocks.** The cascade is real and reasonably predictable: **Waxy or kottke → everything** (both are read by other curators); **Sidebar → Muzli, Web Designer News, a dozen scraper newsletters** automatically; **Hover States → Awwwards/CSSDA jurors notice you without paying**; **Naive Weekly → Dense Discovery, Web Curios, Tiny Awards** (that circle reads each other closely); **Frontend Focus → conference CFP invitations**. Bank the first placement, then quote it in wave two.
8. Cross-post every placement to [Bluesky/Mastodon](./11-bluesky-mastodon.md) — that's where these curators actually hang out, and being visible there raises the next pitch's odds.

## How we'll know it worked

- **Primary metric:** referral sessions per outlet, tagged `?utm_source=<outlet>&utm_medium=newsletter&utm_campaign=design-curators` (e.g. `utm_source=naiveweekly`). Log every send date in [Tracking](./99-tracking.md) so a spike can be attributed even when the curator strips the query string.
- **Success threshold for the whole channel:** ≥2 placements out of ~12 pitches in wave one + two, and ≥3,000 referred sessions inside 30 days.
- **Quality signal that matters more than volume:** palette-export events per session from newsletter traffic vs. baseline. If designers arrive and copy a palette, we hit the right audience; if they bounce in 8 seconds, the pitch was wrong.
- **Evergreen check at 90 days:** Figma Community file duplicates + Gumroad downloads. Anything over ~200 either way justifies expanding the pack.

## Risks

- **Pitching before the site is fast or mobile-clean.** Curators open on a phone. A slow or broken first impression burns a one-shot relationship permanently. Verify mobile before wave one.
- **Sounding like AI or like marketing.** Web Curios explicitly rejects AI-written pitches, and every curator on this list can smell a template. These emails are short on purpose; keep the seams showing.
- **Over-claiming.** If any outlet prints "photographs of exoplanets", we've failed the project's core editorial rule. Put "modelled, not photographed" in the 150-word blurb so the copy-paste is already correct.
- **Traffic spike costs.** The full grid is image-heavy; confirm the static host survives a Sidebar-level day before pitching Sidebar.
- **Newsletter mortality.** Two candidates on this list (Codrops Collective, Designer News) are already dead and one (Typewolf SOTD) looks dormant. Re-verify each outlet the day you send; a bounced pitch is wasted, and a dead outlet in the tracker inflates the plan.
- **Effort sink.** The long tail (Muzli, Web Designer News, Present & Correct, WITI) is where evenings go to die for near-zero referral. Cap the whole channel at two evenings.
