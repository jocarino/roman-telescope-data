The colour

Computed from each planet's reflected-light spectrum ({{ g('albedo-spectrum', 'albedo model') }} × {{ g('host-star', 'host-star') }} spectrum) via {{ g('cie-1931', 'CIE 1931 colour matching') }} — no photographs involved.

Two views

Every planet is shown both ways: the {{ g('full-spectrum-view', 'full modelled spectrum') }}, and what the {{ g('coronagraph', 'Roman Coronagraph') }} would recover from just {{ g('roman-4-band', 'four bands') }}. For Roman's ~dozen {{ g('tech-demo-target', 'tech-demo targets') }}, the four-band view will one day be replaced by real measured data.

Honesty
